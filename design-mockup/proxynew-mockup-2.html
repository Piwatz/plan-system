ระบบไม่ใส่ลายเซ็นครูแทน ช่องลายเซ็นครูในบันทึกข้อความเว้นว่างไว้ให้เซ็นมือ หรือครูกลับมาเข้าระบบแล้วกดยืนยันและใส่ลายเซ็นของตัวเอง

ไฟล์คู่มือรายวิชา

ควรตรวจไฟล์ต้องมีหน้าปกและเนื้อหา รวมเป็น PDF ไฟล์เดียวมาเอง หรือเลือกหลายไฟล์ เช่น ปกกับเนื้อหา แล้วเรียงด้วยปุ่มขึ้นลง เว็บจะรวมให้ก็ได้ หน้าแรกจะเป็นปกในคลังงาน

    หน้าปกที่จะส่ง

    ภาพนี้จะเป็นปกในคลังงาน
    ถ้าหน้านี้ไม่ใช่ปก ให้เลื่อนไฟล์ปกขึ้นไว้บนสุด หรือเลือกไฟล์ใหม่
    หน้าแรกดูเหมือนไม่ใช่ปกหน้านี้แทบไม่มีตัวหนังสือ ถ้าปกอยู่อีกไฟล์ ให้เลือกไฟล์ปกเพิ่มแล้วเลื่อนไว้บนสุด ถ้ายังไม่ได้ทำปก ให้ทำปกก่อน
    มีแต่ไฟล์ Word ทำอย่างไร
    1. Word บน Windows เปิดไฟล์ กด ไฟล์ (File) แล้วเลือก บันทึกเป็น (Save As) ช่องชนิดไฟล์เลือก PDF แล้วกดบันทึก
    2. Word บน Mac เปิดไฟล์ กด File แล้วเลือก Save As ช่อง File Format เลือก PDF แล้วกด Export
    3. Google Docs เปิดไฟล์ กด ไฟล์ เลือก ดาวน์โหลด แล้วเลือก เอกสาร PDF
    4. ถ้าปกกับเนื้อหาอยู่คนละไฟล์ บันทึกเป็น PDF ทั้งสองไฟล์ แล้วเลือกมาพร้อมกันที่ช่องด้านบน ระบบจะรวมให้

    ระบบตรวจไฟล์ให้ทันทีที่เลือก ชนิดไฟล์ ขนาด ไฟล์เปิดได้ และจำนวนหน้า PDF

    ไม่บังคับ ใส่ได้ถ้ามีสื่อหรือไฟล์ประกอบเพิ่มเติม
    ก่อนส่ง ตรวจให้ครบ3/6
    กรอกรหัสวิชา ชื่อวิชา และระดับชั้นครบว31101 วิทยาศาสตร์กายภาพ ม.4
    กรอกเลขที่บันทึกข้อความขอเลขที่ห้องวิชาการ แล้วกรอกเฉพาะตัวเลข
    ไฟล์เป็น PDF ไฟล์เดียวยังไม่ได้เลือกไฟล์
    เปิดไฟล์ได้ ไม่เสีย ไม่ติดรหัสผ่านกำลังตรวจ
    ไม่ซ้ำกับไฟล์ในงานอื่นของคุณไม่ซ้ำ
    ลายเซ็นของคุณมีแล้ว ใช้ในบันทึกข้อความที่พิมพ์จากระบบ
    อยู่ในกำหนดส่งเหลือ 68 วัน ถึง 30 ธันวาคม 2569
    หน้าแรกคือหน้าปกดูภาพหน้าปกที่จะส่งด้านบน ต้องเห็นชื่อวิชาและชื่อครู ไม่ใช่หน้าว่างหรือสารบัญ
    หน้าแรกเกือบว่าง อาจไม่ใช่ปก
    ไม่พบรหัสวิชาใน 3 หน้าแรก
    ชื่อไฟล์มีรหัสวิชาอื่น
    จำนวนหน้าน้อยผิดปกติ
    ข้อแดงต้องแก้ก่อนจึงส่งได้ ข้อส้มระบบเดาไว้ ให้ดูเองด้วยตา แล้วติ๊ก ดูแล้ว ทุกข้อ บันทึกร่างได้ตลอดโดยไม่ต้องตรวจครบ
