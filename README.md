# ระบบส่งแผนการสอนออนไลน์

ครูส่ง **คู่มือรายวิชา** ทุกวิชาที่สอน และ **แผนการจัดการเรียนรู้** เฉพาะวิชาหลัก (ปกติคนละ 1 วิชาต่อภาค) แล้วเขียน **บันทึกหลังแผน** ทีละแผน
ทั้งแผนและคู่มือส่งเป็น **PDF ไฟล์เดียว** ต่อวิชา (ปกกับเนื้อหารวมกัน) ถ้ามีหลายไฟล์ ระบบรวมให้
ผู้ตรวจลงความเห็นและลายเซ็นตามลำดับ และพิมพ์บันทึกข้อความ แบบประเมิน และบันทึกหลังแผนออกมาได้ทันที

| งาน | ผู้ลงความเห็นตามลำดับ | ให้คะแนน |
|---|---|---|
| คู่มือรายวิชา | หัวหน้ากลุ่มสาระ → หัวหน้างานส่งเสริมพัฒนากระบวนการเรียนรู้ → หัวหน้ากลุ่มบริหารงานวิชาการ → รองผู้อำนวยการกลุ่มบริหารงานวิชาการ → ผู้อำนวยการ | แบบประเมิน 20 ข้อ (หัวหน้ากลุ่มสาระ) |
| แผนการจัดการเรียนรู้ | ลำดับเดียวกับคู่มือ | แบบประเมิน 20 ข้อ (หัวหน้ากลุ่มสาระ) |
| บันทึกหลังแผน | หัวหน้ากลุ่มสาระ → รองผู้อำนวยการ → ผู้อำนวยการ | ไม่ให้คะแนน |

ชื่อตำแหน่ง ลำดับ และหัวข้อแบบประเมินแก้ได้ในหน้าผู้ดูแลระบบ

## หน้าตาและฟังก์ชันเสริม

- ธีมสี 10 แบบ (A ถึง J) ผู้ดูแลระบบเลือกในหน้า **ตั้งค่าโรงเรียน** ค่าเริ่มต้นคือ **ธีม I กรมท่าสถาบัน** แนวเดียวกับระบบวัดผลของโรงเรียน ฟอนต์ Noto Sans Thai Looped
- ฟอนต์ทุกธีมเก็บไว้ในเครื่อง ใช้ได้แม้อินเทอร์เน็ตล่ม
- ตราโรงเรียนติดตั้งมาให้แล้ว (`public/img/school-logo.png`) เปลี่ยนได้ในหน้าตั้งค่า ตราครุฑบนบันทึกข้อความใส่แยกได้
- ผู้ใช้แต่ละคนกด **โหมดกลางคืน** และ **ตัวใหญ่** ที่เมนูซ้าย ระบบจำไว้ในเครื่องนั้น
- บนมือถือมีแถบเมนูด้านล่าง ผู้ตรวจให้คะแนนโดยมีแถบรวมคะแนนและปุ่มลงนามติดขอบล่าง

## ลองใช้ด้วยข้อมูลสมมติ

1. ดับเบิลคลิก **`ทดลองใช้ ข้อมูลสมมติ.bat`**
2. เบราว์เซอร์จะเปิดหน้าเข้าสู่ระบบให้เอง (ที่อยู่ `http://localhost:3100`)
3. กดชื่อในกล่อง "โหมดทดลอง" เพื่อเข้าในบทบาทนั้น เช่น ครู หัวหน้ากลุ่มสาระ ผู้อำนวยการ ผู้ดูแลระบบ
   รหัสผ่านของทุกบัญชีทดลองคือ `demo1234`

บน Mac ใช้ไฟล์ **`ทดลองใช้ ข้อมูลสมมติ (Mac).command`** แทน (ดูหัวข้อใช้บน Mac ด้านล่าง)

ข้อมูลทดลองอยู่ในโฟลเดอร์ `data-demo` แยกจากข้อมูลจริง อยากเริ่มใหม่ให้ลบโฟลเดอร์ `data-demo` แล้วเปิดไฟล์ .bat อีกครั้ง

## ติดตั้งใช้งานจริง

1. ติดตั้ง **Node.js 24 LTS** จาก https://nodejs.org (ครั้งเดียว)
2. คัดลอกโฟลเดอร์นี้ไปไว้ในคอมที่จะเป็นเครื่องกลาง (เปิดทิ้งไว้ตลอดเวลาที่ครูใช้งาน)
3. ดับเบิลคลิก **`เปิดระบบส่งแผน.bat`** (ครั้งแรกต้องต่ออินเทอร์เน็ต เพื่อดาวน์โหลดส่วนประกอบประมาณ 1 นาที)
4. หน้า **ตั้งค่าครั้งแรก** จะเปิดขึ้น ให้กรอกชื่อโรงเรียนและสร้างบัญชีผู้ดูแลระบบ
5. ในหน้า **ผู้ดูแลระบบ** ทำตามลำดับ
   1. ตั้งค่าโรงเรียน: ชื่อโรงเรียน อำเภอ จังหวัด ภาคเรียนปัจจุบัน ช่วงวันที่เปิดรับส่ง ธีมสี ตราครุฑ (ไม่บังคับ)
   2. กลุ่มสาระ: มีให้ 8 กลุ่มสาระแล้ว แก้ชื่อได้ (กิจกรรมพัฒนาผู้เรียนไม่ต้องส่งแผน จึงไม่ได้ใส่ไว้)
   3. รายชื่อครู: คัดลอกตารางจาก Excel แล้ววางได้เลย (ชื่อผู้ใช้ ชื่อ สกุล ตำแหน่ง กลุ่มสาระ หน้าที่ผู้ตรวจ) และติ๊กว่าใครเป็นผู้ตรวจระดับไหน
   4. ขั้นตอนการตรวจ: ชื่อตำแหน่งที่จะพิมพ์ในบันทึกข้อความ และระดับที่ใช้กับงานแต่ละชนิด
   5. แบบประเมิน: ใส่แบบประเมินคู่มือรายวิชาและแผนของโรงเรียนไว้ให้แล้ว แก้ได้
6. แจ้งครูให้เข้าระบบ ครูต้องตั้งรหัสผ่านใหม่และเซ็นชื่อในหน้า "ข้อมูลส่วนตัว" ก่อนใช้งานครั้งแรก

### ใช้บน Mac (MacBook)

1. ติดตั้ง **Node.js 24 LTS** จาก https://nodejs.org
2. ดับเบิลคลิก **`เปิดระบบส่งแผน (Mac).command`** (ทดลองใช้ ดับเบิลคลิก `ทดลองใช้ ข้อมูลสมมติ (Mac).command`)
3. ครั้งแรก macOS อาจไม่ยอมเปิดไฟล์ ให้คลิกขวาที่ไฟล์ เลือก **เปิด (Open)** แล้วกด **เปิด** อีกครั้ง
4. ถ้าขึ้นว่าไม่มีสิทธิ์เปิด ให้เปิดโปรแกรม Terminal พิมพ์ `chmod +x ` แล้วลากไฟล์ .command มาวาง กด Enter แล้วดับเบิลคลิกใหม่

เอกสารที่พิมพ์ใช้ฟอนต์ TH SarabunPSK ถ้าเครื่องไม่มี ระบบใช้ Sarabun ที่มากับระบบแทนโดยย่อให้ขนาดเท่ากัน ถ้าต้องการให้ตรงต้นฉบับที่สุด ให้ติดตั้งฟอนต์ TH SarabunPSK ในเครื่อง (ทั้ง Windows และ Mac) แล้วพิมพ์ผ่าน Chrome Edge หรือ Safari ได้ทั้งหมด

### ให้ครูเข้าจากเครื่องอื่น

- หน้าต่างสีดำที่เปิดขึ้นจะแสดงที่อยู่ เช่น `http://192.168.1.38:3000` ครูที่ต่อ Wi-Fi เดียวกันเปิดที่อยู่นี้ได้ทั้งคอมและมือถือ (ดูได้ที่หน้าผู้ดูแลระบบด้วย)
- ครั้งแรก Windows อาจถามเรื่องไฟร์วอลล์ ให้กด **อนุญาต (Allow)** สำหรับเครือข่ายส่วนตัว
- ถ้าต้องการให้เข้าจากนอกโรงเรียน ต้องตั้งค่าเพิ่ม (เช่น Cloudflare Tunnel หรือเช่าเครื่องบนคลาวด์) ค่อยทำเป็นขั้นต่อไป

### แปลงไฟล์ Word เป็น PDF ในระบบ (ไม่บังคับ)

1. ติดตั้งโปรแกรมฟรี **LibreOffice** (libreoffice.org) ในเครื่องที่เปิดระบบเครื่องเดียว ใช้ค่าตั้งต้นทั้งหมด
2. ติดตั้งฟอนต์ที่เอกสารของโรงเรียนใช้ในเครื่องเดียวกัน โดยเฉพาะ **TH SarabunPSK** ครบทั้งตัวปกติ ตัวหนา ตัวเอียง ไม่อย่างนั้นตัวอักษรใน PDF จะเพี้ยน
3. ดูผลที่หน้า **ฟังก์ชันเสริม** กล่อง "ตัวแปลง Word เป็น PDF" ต้องขึ้นว่าพบทั้งโปรแกรมและฟอนต์
4. ครูเลือกไฟล์ Word ในหน้าส่งงานได้เลย ระบบแปลงให้ แล้วครูกด "เปิดดูทั้งไฟล์" ตรวจก่อนส่ง ระบบไม่เก็บไฟล์ Word

### คัดลอกแผนและคู่มือไป Google Drive (ไม่บังคับ)

1. ติดตั้งโปรแกรม **Google Drive for desktop** ในเครื่องที่เปิดระบบ แล้วเข้าสู่ระบบด้วยบัญชี Google ของโรงเรียน
2. หน้า **ฟังก์ชันเสริม** กล่อง "คัดลอกไป Google Drive" กด "หาโฟลเดอร์ Google Drive" แล้วกดเลือก (หรือพิมพ์เอง เช่น `G:\My Drive\ระบบส่งแผน`) เลือกว่าจะคัดลอกเมื่อครูส่งงาน หรือเมื่อผ่านครบทุกระดับ แล้วกดบันทึก
3. เปิดสวิตช์ "คัดลอกแผนและคู่มือไป Google Drive" ระบบคัดลอกงานที่ส่งไว้แล้วทั้งหมดให้ทันที
4. ไฟล์แยกโฟลเดอร์ `ภาคเรียน 2-2569 / กลุ่มสาระ / ชื่อครู / แผนการจัดการเรียนรู้ หรือ คู่มือรายวิชา` ครูส่งไฟล์ใหม่ สำเนาจะเปลี่ยนเป็นฉบับล่าสุด
5. ถ้าเครื่องปิดโปรแกรม Google Drive ไว้ การส่งงานยังทำได้ตามปกติ กลับมาเปิดแล้วกด "คัดลอกทั้งหมดตอนนี้"

## สำรองข้อมูล

ข้อมูลจริงทั้งหมดอยู่ในโฟลเดอร์ **`data`** (ฐานข้อมูล `app.db` และไฟล์ที่ครูส่งในโฟลเดอร์ `uploads`)
คัดลอกทั้งโฟลเดอร์ `data` ไปเก็บในแฟลชไดรฟ์อย่างน้อยสัปดาห์ละครั้ง
หน้าผู้ดูแลระบบมีปุ่มดาวน์โหลดสำรองฐานข้อมูลด้วย แต่ไม่รวมไฟล์ที่ครูส่ง
สำเนาใน Google Drive (ถ้าเปิดใช้) เป็นสำรองอีกชั้นหนึ่งของไฟล์แผนและคู่มือ แต่ไม่รวมฐานข้อมูล

```
│  ├─ features.js              รายการฟังก์ชันเสริม สวิตช์ ประวัติการเปิดปิด ประโยคสำเร็จรูป
│  ├─ line.js                  สรุปงานเข้า LINE ทุกเช้า
│  └─ routes/                  หน้าเว็บแต่ละกลุ่ม (เข้าสู่ระบบ ส่งงาน ตรวจ รายงาน ผู้ดูแล ฟังก์ชันเสริม QR)
├─ views/                      หน้าตาเว็บ และหน้าพิมพ์เอกสาร (print_*.ejs)
├─ public/                     หน้าตา ตราโรงเรียน ป๊อปยืนยัน ช่องเซ็นชื่อ ตรวจไฟล์ ประโยคสำเร็จรูป
├─ scripts/seed-demo.js        สร้างข้อมูลทดลอง (ชื่อครูและผู้บริหารเป็นชื่อสมมติ)
├─ tests/                      ตัวทดสอบอัตโนมัติ
├─ data/                       ข้อมูลจริง (ไม่ขึ้น Git)
└─ data-demo/                  ข้อมูลทดลอง (ไม่ขึ้น Git)
```

## สำหรับผู้พัฒนา

```bash
npm install
npm test          # ทดสอบอัตโนมัติทั้งหมด
npm run demo      # สร้างข้อมูลทดลองใหม่แล้วเปิดที่ http://localhost:3100
npm start         # เปิดใช้งานจริงที่ http://localhost:3000
```

ใช้ Node.js 22.13 ขึ้นไป (ฐานข้อมูล SQLite ที่มากับ Node) Express 5 EJS ฟอนต์จาก @fontsource และ QR Code จาก qrcode
ตั้งพอร์ตหรือโฟลเดอร์ข้อมูลอื่นได้ด้วย `node server.js --port 8080 --data D:\plan-data`
